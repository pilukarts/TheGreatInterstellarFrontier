# 🔭 Glosario del universo

[← Inicio](README.md)

| Término | Significado público |
|---|---|
| **The Great Interstellar Frontier** | Título del universo y videojuego en desarrollo de Pilukarts Studio |
| **Frontier Ark** | Ciudad-nave de gran tamaño que alberga población humana durante el éxodo |
| **Anillo habitable** | Estructura tubular exterior con siete plantas residenciales y de servicios |
| **Torre central** | Centro de mando y administración de la nave |
| **Santos Sabios** | Mayores y maestros muy respetados por la civilización |
| **Gran Guerra** | Conflicto histórico cuyas consecuencias todavía marcan a la sociedad |
| **Memorial Day** | Día de recuerdo para todas las personas fallecidas en la Gran Guerra |
| **Brigada 60** | Equipo de rescate destacado en la misión Operación Esperanza; posible proyecto derivado |
| **Centinela 03** | Patrulla espacial de los registros de misiones |
| **Aurora 02** | Nave de rescate |
| **Atlas** | Remolcador utilizado en recuperación de material |
| **ARGOS-6** | Dron de exploración |
| **AF-S17** | Identificador provisional de un fragmento recuperado en una misión |
| **Pilukarts Studio** | Estudio creador del universo y sus proyectos relacionados |

## Nombres y continuidad

El nombre anterior **Ark-Forge** apareció en documentación y prototipos tempranos. **Frontier Ark** es el nombre actual para la nave; el título del juego es **The Great Interstellar Frontier**.

Algunos nombres técnicos antiguos o rutas de archivo todavía pueden conservar grafías previas por compatibilidad. No deben confundirse con el nombre público vigente.
